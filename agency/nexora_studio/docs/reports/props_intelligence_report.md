## 2. Dynamic Variant Adaptation

Rather than generating separate component files for different layout styles, the React Component Library implements enumerated variant dictionaries within component synthesizers. Section generators pass a simple `variant` prop that reconfigures the internal JSX layout and CSS styling dynamically.

### Core Component Variants Validated

| Component | Supported Variants | Layout & Styling Behavior |
| :--- | :--- | :--- |
| **`Button`** | `primary`, `secondary`, `outline`, `ghost`, `link` | Adapts background color, border width, text color, and hover states using design token variables. |
| **`Hero`** | `centered`, `split`, `fullscreen` | Switches between single-column centered text, 2-column split media/text grid, and 100vh viewport-filling backgrounds. |
| **`Navbar`** | `standard`, `transparent`, `sidebar` | Adapts container positioning (sticky header vs. absolute overlay vs. vertical side navigation). |
| **`Card`** | `elevated`, `outlined`, `flat` | Toggles box-shadow depth (`var(--shadow-md)`), subtle border outlines, or minimalist flat backgrounds. |
| **`Badge`** | `default`, `primary`, `success`, `warning`, `error`, `info` | Modifies color schemes to convey semantic status alerts cleanly. |

## 3. Props Forwarding & Fallback Intelligence

Section synthesizers generated by `ReactGenerationEngine` employ a robust 3-tier fallback architecture when binding data to library components:

```javascript
title={secData.title || props.title || "Default Component Title"}
```

1. **Content Binding Layer (`secData`):** Resolves dynamic text and structured arrays from `src/config/content.js`, generated by the Content Intelligence Engine (Phase 11F).
2. **Runtime Prop Override (`props.title`):** Allows parent page components or routing wrappers to pass custom prop overrides at runtime.
3. **Authoritative Fallback:** Guaranteed clean strings or default data structures (e.g., default user rows in `Table.jsx`, default product cards in `ProductGrid.jsx`) ensuring that components never crash due to `undefined` or `null` data.

Furthermore, all wrapper components implement clean prop spreading (`{...props}`) to pass HTML attributes, event handlers (`onClick`, `onKeyDown`), and custom CSS classes down to the DOM root.

## 4. Accessibility (a11y) & Semantic Metadata Audit

A critical mandate of Phase 12B is WCAG compliance by default. The synthesis engine embeds accessibility metadata directly into generated JSX structures without requiring user intervention:

- **Semantic HTML5 Elements:** Organisms and molecules strictly utilize semantic tags: `<nav>` for navigation, `<main>` for primary page wrappers, `<header>` and `<footer>` for landmark regions, and `<article role="region">` for content cards.
- **ARIA Labeling & Roles:** Interactive elements without descriptive text payloads automatically receive `aria-label` bindings (e.g., `<article aria-label={title || 'Content Card'}>`, `<button aria-label="Close modal">`).
- **Keyboard Navigation & Focus Control:** Interactive components (such as clickable cards, modals, and pagination controls) include explicit `tabIndex={0}` attributes and keyboard event listeners (`onKeyDown`), paired with universal focus rings (`*:focus-visible { outline: 2px solid var(--color-primary); }`).
