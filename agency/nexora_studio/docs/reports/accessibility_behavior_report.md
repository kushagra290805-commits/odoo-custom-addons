## 3. Keyboard Navigation & Shortcut Standards

In accordance with WAI-ARIA APG guidelines, synthesized components implement standardized keyboard navigation shortcuts without relying on mouse interaction:

### 3.1 Modal Dialog Shortcuts
- **`Escape`**: Pressing the Escape key anywhere within an open dialog immediately dismisses the modal and triggers the close state transition.
- **`Tab` / `Shift+Tab`**: Traverses focusable elements inside the dialog. Focus is trapped within the dialog boundaries while open.

### 3.2 Accordion Shortcuts
- **`Enter` / `Space`**: When focus is on an accordion header button, pressing Enter or Space toggles the expansion state of the associated content panel.
- **`ArrowDown` / `ArrowUp`**: Moves DOM focus to the next or previous accordion header button in the group, cycling smoothly from the last item back to the first.

### 3.3 Tabs Navigation Shortcuts
- **`ArrowRight` / `ArrowLeft`**: When focus is on a tab within a `tablist`, pressing ArrowRight moves focus and active selection to the next tab; ArrowLeft moves to the previous tab.
- **`Home` / `End`**: Moves focus and active selection directly to the first or last tab in the tablist.

### 3.4 Dropdown Menu Shortcuts
- **`ArrowDown` / `ArrowUp`**: Navigates through listbox options while updating visual focus styling and `aria-selected` attributes.
- **`Enter` / `Space`**: Selects the currently focused listbox option and closes the dropdown menu.
- **`Escape`**: Closes the dropdown menu without selecting an option and returns focus to the dropdown trigger button.

## 4. Focus Management & Focus Trapping

Focus management is a critical requirement for WCAG 2.1 Level AA compliance in overlay and modal components:

### 4.1 WCAG 2.1 Focus Trapping in Modals
When `<Modal />` mounts with `isOpen={true}`, the component executes a DOM focus trapping algorithm:
1. Queries all focusable elements inside the dialog container using:
   `modalRef.current.querySelectorAll('button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])')`.
2. Sets initial focus to the first focusable element inside the modal.
3. Attaches an `onKeyDown` listener intercepting `Tab` key presses:
   - If `Tab` is pressed on the last focusable element, focus wraps around to the first element (`first.focus()`).
   - If `Shift+Tab` is pressed on the first focusable element, focus wraps backward to the last element (`last.focus()`).

### 4.2 Active Element Focus Restoration
To prevent focus loss when dialogs or dropdown menus close:
- Upon modal opening, the component stores a reference to the previously focused DOM element:
  `previousFocusRef.current = document.activeElement;`.
- When the modal closes (via Escape key, close button, or background overlay click), the cleanup effect or close handler explicitly restores focus:
  `if (previousFocusRef.current) previousFocusRef.current.focus();`.
- Similarly, dismissing a dropdown menu via Escape restores focus directly to the dropdown trigger button.
